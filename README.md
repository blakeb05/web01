# 💖 Romantic Quiz & Proposal Website

A beautiful, modern, and interactive romantic quiz website that leads to a marriage proposal! This project features warm romantic vibes, modern styling, and is optimized for iOS devices.

## ✨ Features

- **Beautiful Homepage** with romantic decorations and animations
- **Interactive Quiz** with 6 romantic questions leading to the big question
- **Marriage Proposal** as the final quiz question with special effects
- **Photo Gallery** that unlocks after quiz completion
- **Modern Design** with warm romantic colors and smooth animations
- **iOS Optimized** for perfect mobile experience
- **Romantic Animations** including floating hearts, petals, and sparkles
- **Interactive Elements** with hover effects and click animations
- **Responsive Design** that works beautifully on all devices

## 🌹 How It Works

1. **Start Page**: Welcome screen with "Begin Our Story" button
2. **Quiz Journey**: 6 romantic questions about your relationship
3. **The Big Moment**: "Will you marry me?" as the final question
4. **Celebration**: Beautiful celebration effects when "YES" is chosen
5. **Gallery Unlock**: Access to a romantic photo gallery
6. **Memory Lane**: Interactive photo gallery with romantic messages

## 🚀 Getting Started

1. **Clone or Download** this repository
2. **Open `index.html`** in your web browser
3. **Click "Begin Our Story"** to start the quiz
4. **Answer the questions** to reach the proposal
5. **Say YES!** to unlock the gallery
6. **Explore the gallery** to see your beautiful memories

## 💝 Customization

### Personalizing the Questions
Edit the `quizData` array in `quiz.js` to customize the romantic questions:

```javascript
const quizData = [
    {
        question: "Your personalized question here?",
        answers: [
            "Option 1 💕",
            "Option 2 💖",
            // ... more options
        ]
    },
    // ... more questions
];
```

### Adding Real Photos
Replace the photo placeholders in `gallery.html` with real images:

```html
<div class="photo-placeholder">
    <img src="your-photo.jpg" alt="Description" style="width: 100%; height: 100%; object-fit: cover; border-radius: 15px;">
</div>
```

### Customizing Colors
Modify the color scheme in `styles.css`:

```css
/* Main gradient background */
background: linear-gradient(135deg, #your-color1, #your-color2);

/* Button colors */
background: linear-gradient(45deg, #your-accent1, #your-accent2);
```
